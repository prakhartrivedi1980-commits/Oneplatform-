# OnePlatform

OnePlatform is a unified coding progress and analytics platform for students.

It brings coding activity from platforms such as LeetCode, CodeChef, HackerRank and Codeforces into one dashboard.

## Planned Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- NestJS
- Supabase PostgreSQL
- Prisma
- Redis
- BullMQ
- Docker
